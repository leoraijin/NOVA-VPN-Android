# NOVA VPN для Android

Основной Android-клиент **0.2.49 (51)**: Reality Core, sing-box, локальные
идентичности и зашифрованный перенос теперь в обычном `com.nova.vpn.android`.
Прежняя подпись и автообновления сохранены: устанавливайте поверх основной NOVA,
не удаляя приложение. Отдельные тестовые пакеты автоматически не объединяются.

Последние исправления подписок/HWID и ручного HTTPS-замера из 0.2.48 включены.
Редактор идентичностей хранит данные локально; сам по себе он не подключает
их к HTTP-запросам. HWID при импорте по-прежнему включается отдельным флажком.

Reality Core выбирается в Настройки → VPN-движок. Существующий выбор сохраняется,
sing-box остаётся значением по умолчанию. Новый движок имеет экспериментальные
ограничения: реальные провайдеры/все транспорты не подтверждены локальными тестами.
Исторический PHONE-TEST-2026-10-16.txt содержит один необъяснённый сбой bootstrap;
не считать его исправленным. [Ограничения](REALITY-CORE-INTEGRATION.md),
[изменения](CHANGELOG.md), [предупреждение Play Защиты](PLAY-PROTECT.md).

Русская документация.

Самостоятельный Android-клиент NOVA VPN. Он отделён от клиента Windows и не заменяет его.

## Возможности локального исходного проекта

- Подписки с HWID: в окне импорта включите «Передавать провайдеру ID устройства»
  только если этого требует ваш провайдер. Это может занять отдельный слот.
  ID случайный, разный для разных HTTPS-origin, стабилен до переустановки/очистки
  данных NOVA; не копирует идентификатор v2rayTun и не обходит лимит устройств.
  IMEI, серийный номер и Android ID не используются. При переустановке может
  потребоваться удаление старой привязки в кабинете провайдера.
- Подключение через Android `VpnService` и Android-сборку движка sing-box (`libbox`).
- Добавление VPN-конфигураций из текста/ссылки, QR-кода или выбранного файла; приложение использует системный выбор документов, а не широкий доступ ко всему хранилищу.
- В исходном парсере предусмотрены форматы VLESS, Trojan, Hysteria2/Hy2, TUIC, VMess, Shadowsocks и JSON-конфигурация sing-box. Поддержка конкретных опций зависит от парсера и движка; не всякая ссылка или функция протокола гарантированно совместима.
- Маршрутизация по сайтам/доменам и приложениям. В локальном генераторе конфигурации правила сайтов располагаются раньше правил приложений.
- Иконки установленных приложений и несколько визуальных профилей.
- Локальная карта стран и городов с перетаскиванием, зумом двумя пальцами, кнопками масштаба и выбором профиля по точке.
- Однократная проверка задержки через прокси только по кнопке: зелёная точка означает успешный ответ, красная — ошибку/отсутствие ответа, серая — отсутствие подтверждённой проверки.
- Локальное хранилище секретов профилей использует AES-GCM с ключом Android Keystore. В манифесте отключён backup приложения.

Отдельный клиент часов опубликован в [NOVA-VPN-WearOS](https://github.com/leoraijin/NOVA-VPN-WearOS). Совместимость телефона и часов, соединение VPN, QR-сканер и передача профилей требуют тестирования на реальных устройствах.

## Совместимость и сборка

Параметры проекта: `minSdk 24`, `targetSdk 35`, `compileSdk 35`; версия `0.2.33` (versionCode 35). Используются JDK 17, Gradle Wrapper 8.9 и Android Gradle Plugin 8.7.3.

После установки JDK 17 и Android SDK Platform 35 из корня проекта выполните:

```powershell
.\gradlew.bat testDebugUnitTest
.\gradlew.bat assembleOptimized
```

ABI-варианты APK и universal APK создаются в `app\build\outputs\apk\optimized\`. Эти экспериментальные APK подписаны прежним тестовым ключом для совместимости обновлений. Локальный вспомогательный `Build-Android.ps1` настроен на пути `D:\NOVA-VPN\toolchain`; для переносимой сборки используйте Gradle Wrapper и локально установленный SDK.

## Карта и ручная проверка

Карта встроена в приложение и работает без загрузки тайлов. Локация определяется по названию профиля: город, страна или флаг. Точка страны приблизительная; это не проверенная геолокация IP. Профили без распознанного места остаются в списке ниже карты. Несколько профилей в одной точке объединяются; повторное нажатие переключает профиль внутри группы.

Кнопка «Проверить» один раз проходит по профилям и измеряет время короткого HTTPS-запроса через каждый прокси. Проверка ограничена по времени и выполняется последовательно. Вход во вкладку, запуск приложения и смена сети сами не запускают проверку профилей. Результаты с временем проверки хранятся в памяти текущего сеанса. Красный цвет означает неудачную пробу, а не окончательную неисправность сервера.

Кнопка «Стоп», уход со вкладки, сворачивание приложения и начало подключения останавливают проверку. Каждый профиль проверяется в отдельном временном процессе; после завершения/отмены процесс закрывается вместе с сокетами и временным конфигом. В этой версии массовая проверка поддерживает отдельные VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC; полные JSON-документы остаются серыми с пояснением «Проверка не поддерживается».

Тестовая копия с отдельным applicationId `.maptest` собирается командой `Build-Android.ps1 --offline --no-daemon -PnovaMapSmoke assembleMaptest assembleMaptestAndroidTest`. Она использует искусственные профили и не читает хранилище основной установленной NOVA.

## Конфиденциальность и безопасность

Не публикуйте профили, приватные ключи, подписочные URL и логи с секретами. В исходниках есть локальное шифрованное хранилище профилей, но это не заменяет оценку резервного копирования, модели угроз или независимый аудит. Клиент взаимодействует с выбранными VPN-серверами/подписками и GitHub для проверки выпусков; заявления об отсутствии телеметрии или об анонимности не подтверждены аудитом.

Движок Android подключён через `com.github.singbox-android:libbox:1.14.1`; локальный [THIRD-PARTY-NOTICES.md](THIRD-PARTY-NOTICES.md) указывает GPL-3.0-or-later для upstream-компонента. До распространения APK владелец должен проверить совместимость лицензирования приложения с GPL и выполнить обязанности по предоставлению исходного кода/уведомлений. Эта сторонняя лицензия не является лицензией NOVA VPN.

О правилах сообщений об уязвимостях см. [SECURITY.md](SECURITY.md). Частный канал нужно настроить и проверить владельцу; не отправляйте секреты в публичные Issues.

## Экспериментальное Reality Core

Ветка `experiment/reality-core` добавляет необязательное второе ядро. Выбор находится
в настройках всех оформлений. По умолчанию работает sing-box. Обновления тестового
пакета устанавливаются вручную из prerelease; стабильное автообновление не изменено.
