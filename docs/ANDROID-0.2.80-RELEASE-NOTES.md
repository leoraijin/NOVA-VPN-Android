# NOVA VPN Android 0.2.80

- В «Маршруты → Приложения» в карточке приложения появилась кнопка «Через DNS». Можно выбрать сохранённый DNS-сервер или добавить новый. После выбора карточка показывает его название.
- У разных приложений могут быть разные DNS. Назначение заменяет прежний маршрут приложения. Выбор «Напрямую» или любого VPN снимает назначение DNS.
- Приложение использует выбранный DNS с прямым подключением на Android 10 и новее с ядром sing-box. Сохраняется приоритет правил для отдельных сайтов. Приложения с собственным зашифрованным DNS могут использовать свой резолвер.
