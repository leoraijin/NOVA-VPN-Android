# Android 0.2.69

Состояния основного VPN и VPN-2 перенесены в общий блок «Два VPN-конфига» на главной странице. Отдельные карточки над главным экраном удалены.

Блок по умолчанию свёрнут. Нажатие на заголовок раскрывает переключатель режима, названия и состояния действующих конфигов и кнопку выбора серверов. Повторное нажатие сворачивает блок, не меняя режим и подключение. Состояние раскрытия сохраняется при пересоздании экрана. Содержимое ограничено по высоте и прокручивается при крупном шрифте. Цвета и форма берутся из выбранной темы.

Маршрутизация и уведомление не изменены. Сборка optimized и встроенная проверка lintVital завершились успешно. Подпись APK соответствует предыдущей версии. Физический телефон недоступен, визуальная проверка на устройстве не выполнена.
