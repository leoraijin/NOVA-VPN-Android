# NOVA VPN Android 0.2.79

На главном экране под управлением VPN появился выбор DNS. Можно добавить до 20 серверов, выбрать активный, изменить или удалить запись.

Поддерживаются IP-адрес DNS, UDP, TCP, DNS-over-TLS и DNS-over-HTTPS. Для выбранного сервера задаётся список сайтов. Эти домены и их поддомены разрешаются выбранным DNS и открываются напрямую. DNS-правила применяются раньше назначений VPN, явные блокировки сохраняют приоритет.

Настройки сохраняются в профиле маршрутизации и входят в его экспорт. Выбор обычной маршрутизации выключает отдельные DNS-правила. Переключение режима нескольких VPN сохраняет выбранный DNS и список сайтов.

Функция в этой версии работает для сайтов с ядром sing-box. Приложения со встроенным защищённым DNS могут обходить DNS клиента.

Сборка APK и 582 unit-теста прошли, два теста пропущены. Сетевой стенд с настоящим sing-box проверил выбранный DNS и прямое подключение в одиночном и многосерверном режиме. На физическом Android новая функция пока не проверена, телефон не подключён.
