# Android 0.2.70 — обмен ключами и маршрутами

В Настройки → Поделиться и перенести добавлены:
- «Ключи + маршрутизация»: все доступные ключи и все сохранённые профили маршрутизации в файле с паролем от 10 символов. Пароль передаётся получателю отдельно. Ссылки подписок и идентификация подписок не экспортируются.
- «Только маршрутизация»: JSON с правилами сайтов и приложений, назначениями VPN-1/VPN-2 и историей переключения режима, без конфигов и ссылок подписок.
- Отправка через системное меню Android, сохранение файла и импорт из файла.

При импорте маршрутов без ключей выбираются местные серверы для назначений. Существующие ключи сохраняются, одинаковые конфиги не дублируются. Полученные профили маршрутизации добавляются отдельно; выбранный отправителем профиль становится активным. Импорт возможен при отключённом VPN и не включает подключение автоматически. Тема, идентификация подписок и остальные настройки приложения не меняются. При ошибке или прерывании записи журнал восстанавливает прежние ключи и маршруты.

Раздел использует общие компоненты текущей темы во всех пяти вариантах оформления. Новый формат предназначен для импорта в Android NOVA 0.2.70 и новее.

Проверки:
- :app:testOptimizedUnitTest + :app:assembleOptimized — успешно; 564 теста, 563 успешно, 1 ранее существовавший пропущен. Проверены оба формата, отсутствие секретов в варианте без ключей, пароль, назначение двух VPN, совпадения и смена ID, сохранность старых профилей, откат при ошибке и запись журнала перед изменениями.
- Дополнительный RoutingShareProviderTest: проверка узкой области FileProvider прошла; проверка открытия content URI пропущена на Windows из-за различия разделителей файловых путей AndroidX. Этот тест оставлен для Unix/устройства.
- optimized APK, lintVital и подпись проверены; сертификат прежний.
- Физический телефон недоступен. Системное меню отправки, выбор файла и визуальная проверка всех тем на устройстве пока не выполнены.
