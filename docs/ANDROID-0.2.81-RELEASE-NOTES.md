# NOVA VPN Android 0.2.81

- Правила удалённых приложений больше не блокируют изменение маршрутов во время работы VPN. Они остаются в профиле и снова применяются после установки приложения.
- Предупреждения редактора маршрутов отображаются в самом редакторе. Главная показывает состояние VPN-подключения.
- При добавлении DNS для приложения выбор закрывается после подтверждения сохранения. Если VPN не применил изменение, диалог объясняет причину и оставляет введённый сервер для повторной попытки.
