# NOVA VPN Android 0.2.77

- В фоне основной выход проверяется раз в 2 минуты, дополнительные — раз в 10 минут. При возврате в приложение и смене сети план проверок обновляется.
- Ручная проверка использует одну HTTPS-цель и пробует запасную, если первая не отвечает. Автоматический выбор сервера продолжает использовать серию замеров.
- Список серверов читает защищённый каталог один раз на обновление. Поиск использует общий индекс, окно выбора VPN загружает строки по мере прокрутки.
