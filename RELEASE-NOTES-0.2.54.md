# NOVA VPN Android 0.2.54

Исправлено получение сокращённого каталога подписки: клиент автоматически выбирает
поддержанный формат с большим числом подключений и сохраняет его для обновлений.
Добавлен разбор Hysteria 2 в JSON-конфигах Xray, включая экспортированный QUIC debug=false.

На реальной подписке вместо 9 ссылок получены 76–77 уникальных подключений
из 52 JSON-профилей, без ошибок разбора: TCP, gRPC и Hysteria 2.
Для этой подписки необходим включённый флажок «Передавать провайдеру ID устройства».
После обновления приложения обновите саму подписку во вкладке «Подписки».

На TECNO проверены реальный TUN, TCP в обоих движках, Hysteria 2 в sing-box,
прямое исключение сайта, незахваченный UID и возврат маршрута после STOP.
Три проверенных gRPC-сервера не заработали в обоих движках; причина пока не установлена.
Работоспособность всех серверов не заявляется. XHTTP в ответе этой подписки отсутствовал.

Сборка ARM64 optimized успешна. Unit: 344 всего, 343 PASS, 1 optional skipped.
Прежние package ID и подпись сохранены; устанавливайте поверх основной NOVA без удаления данных.
Native-библиотеки не менялись относительно 0.2.52.

Исходники и лицензии неизменённых ядер доступны в [выпуске 0.2.52](https://github.com/leoraijin/NOVA-VPN-Android/releases/tag/v0.2.52).
