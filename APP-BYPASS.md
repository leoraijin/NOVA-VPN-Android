# Исключение приложений из VPN

Изменение после 0.2.50: выбранные исключения применяются на уровне Android
VpnService.Builder, а не только как direct-outbound внутри ядра.

- «Все, кроме отмеченных»: exclude_package включает отмеченные пакеты и NOVA.
- «Только отмеченные», непустой список: include_package включает выбранные
  приложения без NOVA. Остальные приложения не попадают в VPN-интерфейс.
- Правила сайтов действуют внутри приложений, допущенных в VPN. Они больше
  не возвращают исключённый браузер в туннель.
- sing-box получает списки через Android platform API; Reality Core переносит
  проверенные списки в Builder и удаляет их из нативной конфигурации. Несовпадение
  списка с проверенными правилами вызывает ошибку вместо молчаливого захвата.
- Если все пакеты непустого allow-list удалены, sing-box не создаёт VPN для
  всех остальных приложений по ошибке.

Пустой режим «Только отмеченные» сохраняет прежний план direct по умолчанию
с возможностью правил сайтов внутри TUN. Это не системное исключение всех
пакетов. Чтобы исключить конкретное приложение, используйте список исключений
либо непустой список приложений для VPN.
Reality Core сохраняет прежние ограничения совместных правил: Android 10+
и проверка UID. Android lockdown («Блокировать соединения без VPN») может
блокировать прямой доступ исключённых приложений; клиент не обходит эту политику.

## Что это не гарантирует

Это исправление маршрутизации и DNS исключённых приложений. Оно не скрывает
сам факт существования VPN от всех методов проверки Android/сетевых интерфейсов
и не меняет чужие приложения. Нельзя обещать «VPN невозможно обнаружить».
https://developer.android.com/develop/connectivity/vpn#per-app
https://developer.android.com/reference/android/net/NetworkCapabilities#TRANSPORT_VPN

## Проверка на телефоне перед релизом

Для sing-box и Reality Core: отметить браузер как исключённый, оставить
VPN-правило его тестового домена; проверить обычный внешний IP браузера,
обычную DNS-сеть и VPN-IP другого приложения. Повторить для непустого
«Только отмеченные», IPv4/IPv6, Wi-Fi/мобильной сети, перезапуска VPN и
удалённого выбранного приложения. Повторить с lockdown, ожидая блокировку
прямого доступа. Отдельно проверить конкретное приложение, сообщающее о VPN:
его детектор может продолжать обнаруживать VPN несмотря на правильный bypass.
Проверки конфигурации не заменяют эти тесты на устройстве.
