# NOVA VPN Android 0.2.53

Во вкладке «Серверы» добавлена кнопка **«Удалить все конфиги VPN»** для всех тем оформления.

После подтверждения удаляются все серверы и источники подписок на этом устройстве. VPN отключается,
текущие проверки отменяются, сохранённый выбор сервера и набор авторежима сбрасываются.
Для возврата серверов нужен новый импорт. Настройки приложения, маршрутизации и идентификации сохраняются.

Удаление сохраняется в зашифрованном хранилище атомарно. Поздний ответ ранее запущенного обновления
подписки не может восстановить удалённые конфиги. При обнаружении повреждённого хранилища операция
отказывается его перезаписывать.

Проверено: сборка ARM64 optimized; 330 unit-тестов (329 успешны, один необязательный пропущен).
На TECNO KM4 отдельный тестовый пакет прошёл фоновые проверки реального Android Keystore,
удаления и повторного чтения, поздних HTTP 200/304/401, повторного удаления, отказа повреждённого
хранилища и сохранения настроек. Интерфейсный тест добавлен, но не завершён: телефон одновременно
использовался другим UI-тестом. Проверка удаления во время активного туннеля этим запуском не выполнена.

APK: Android 7.0+, ARM64, versionCode 55; прежний сертификат подписи.
Все ARM64 native-библиотеки побайтно совпадают с опубликованным APK 0.2.52.
Исходники и лицензии неизменённых ядер доступны в [выпуске 0.2.52](https://github.com/leoraijin/NOVA-VPN-Android/releases/tag/v0.2.52).
