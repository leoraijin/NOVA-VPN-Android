# NOVA VPN Android — изменения

## 0.2.44

- Оформление Material переработано в Pixel; сохранён идентификатор настройки MATERIAL_YOU.
- Исправлены соответствие оттенка ползунку, всплывающие меню профилей и анимация раскрывающих стрелок.
- Убраны искусственные овальные контуры Liquid Glass, усилено размытие.
- Обучение адаптируется к высоте экрана и крупному шрифту, длинный текст прокручивается, кнопки переносятся.
- Обычный пакет com.nova.vpn.android, versionCode 46 и прежний сертификат сохранены для обновления через стандартный Android-репозиторий.

## 0.2.43

- Четыре оформления: iOS Liquid Glass, Material You, One UI и Windows 11, независимые светлый/тёмный режимы, настройка оттенка и матирования.
- Новая адаптивная иконка; Amber удалён с миграцией старых настроек.
- Уточнены сообщения об ошибках отдельных запросов, успешная HTTPS-проверка очищает прежнее предупреждение.
- Обычный APK с прежним пакетом и сертификатом опубликован как v0.2.43.


## 0.2.33

- Во вкладке «Серверы» добавлена локальная географическая карта. Перетаскивание одним пальцем, масштабирование двумя, двойное нажатие, кнопки `+`/`−`, обзор мира и возврат к выбранному серверу.
- Точки выбирают профили. Локация берётся из названия/флага, без определения по IP; профили без распознанной локации доступны в списке. Близкие точки объединяются с числом профилей.
- «Проверить» запускает один проход по профилям только вручную. Зелёный — HTTPS-запрос через профиль успешен, красный — ответа нет/ошибка, серый — не проверен или проверка не поддерживается. Задержка и время проверки видны на карте и в карточках.
- Проверки выполняются последовательно с ограничением времени. «Стоп», уход со вкладки, сворачивание и начало VPN-подключения отменяют проверку; временный процесс закрывает нативные сокеты и освобождает ресурсы.
- Поддержаны отдельные VLESS, VMess, Trojan, Shadowsocks, Hysteria2 и TUIC. Произвольные полные JSON не запускаются массовой проверкой, чтобы не активировать их внутренние группы/таймеры; для них остаётся серый статус с пояснением.

## 0.2.32

- При установке новой версии автоматическая проверка обновлений запускается сразу, даже если предыдущая версия недавно уже проверяла GitHub; затем снова действует интервал шесть часов.
- В настройках показывается установленный номер версии, чтобы проще проверить получение обновления.
- Остальные функции и поведение VPN не менялись.

## 0.2.31

- Автоматическая проверка обновлений выполняется при открытии приложения не чаще раза в шесть часов, без фонового таймера. Ручная проверка остаётся доступна сразу.
- Поиск приложений перенесён с потока интерфейса на фоновый, с отменой устаревших запросов и короткой паузой при наборе; поисковые строки подготавливаются один раз.
- Android может освободить кеш иконок при нехватке памяти; при скрытии интерфейса остаётся не более 16 кешированных иконок вместо 64.
- Уведомления транспорта больше не вызывают лишние обновления системной плитки. Задачи плитки отменяются при уничтожении её службы; повторные задачи обновления не накапливаются.
- Быстрые серверы больше не требуют сортировки всей подписки при обновлении состояния. Убраны повторное создание Regex диагностики и временного набора в обработчике владельца соединения.
- Параметры туннеля, TLS, маршрутизации и проверки сертификатов не изменены. Процент экономии батареи не заявляется: нужен замер на физических устройствах.

## 0.2.30

- Диагностика подключения: на главной видны версия приложения и кнопка «Скопировать диагностику». После воспроизведения сбоя отчёт можно вставить в сообщение разработчику.
- Отчёт содержит последние 40 событий в памяти: этап запуска, вид физической сети, этап контрольного HTTPS-запроса, код SOCKS-ответа и категории ошибок ядра, включая gRPC Unavailable, TLS, DNS и timeout.
- Сырые сообщения ядра не сохраняются и не экспортируются. Отчёт не содержит ключи, UUID, имя профиля, домены/IP сервера, подписки и посещённые сайты; отправка не выполняется автоматически.
- Это диагностическое обновление для пока не воспроизведённого подключения из отзыва. Оно само по себе не заявляет исправление этого профиля.

## 0.2.29

- Material You: динамические цвета обоев Android 12+, светлый/тёмный режим следует системе; на старых Android используется статическая палитра. Добавлена отдельная Liquid Glass Dark. Темы видны сеткой.
- Исправлен импорт явного TLS ALPN и пустого SNI; добавлен VMess/gRPC. Для ALPN, потерянного старым импортом, нужно заново импортировать исходную ссылку. Пустой SNI сохранённых TLS-профилей получает имя сервера при подключении.
- В стандартных профилях DNS по умолчанию использует IPv4: это устраняет воспроизведённый случай, когда HTTPS-проверка проходит, а браузер пытается использовать недоступный IPv6 VPN-сервера. Маршрутизация → «IPv6 через VPN» включает IPv6-ответы при поддержке сервером. Явный DNS полного JSON сохраняется; bootstrap и DNS сайтов «Напрямую» остаются dual-stack.
- На главной видны безопасные подсказки для ошибок gRPC/serviceName, TLS/ALPN и DNS. В optimized читаются только сообщения ядра для подсказок; подробные соединения и запись сырых логов остаются выключенными.
- На MuMu проверен тестовый VLESS/gRPC-туннель, контрольный HTTPS и открытие домена браузером после исправления. Точный TLS-профиль друга пока не предоставлен, поэтому его успешное подключение ещё требует подтверждения.

## 0.2.28

- Распространяемая сборка `optimized` без режима отладки: выключены отладочные проверки Compose и подробный поток событий/соединений sing-box. Сохранён прежний сертификат для установки поверх существующего клиента; сборка остаётся экспериментальной.
- Непрозрачные карточки без теней уменьшают слои отрисовки при прокрутке; списки серверов и сайтов переиспользуют строки своего типа.
- Монитор физической сети учитывает позднее появление интерфейса после смены Wi-Fi/мобильной сети. Одинаковые события больше не передаются ядру повторно; новая сеть, потеря сети и восстановление интерфейса передаются.
- Это исправление клиентской обработки сети; доступность конкретного сервера и скорость мобильного оператора требуют проверки на устройстве.

## 0.2.27

- Пошаговое обучение при первом открытии: добавление ключа/подписки/QR/файла, маршрутизация приложений, правила сайтов, выбор сервера, обновления с GitHub и подключение VPN.
- Шесть шагов переключают реальные вкладки, прокручивают к нужному блоку и выделяют карточку. Навигация обучения не подключает VPN и не меняет профили или маршруты.
- Кнопки «Назад», «Далее», «Готово» и «Пропустить»; сохранение шага при пересоздании экрана. Завершение/пропуск сохраняются до закрытия подсказок вне UI-потока. Повтор: Настройки → Обучение → Начать обучение.
- Длинный текст прокручивается отдельно; кнопки остаются видимыми. Автоматический запрос разрешения уведомлений и проверка обновлений отложены до выхода из обучения.
- Подпись в настройках уведомлений приведена к тихому поведению 0.2.26; само одно тихое уведомление сохранено.

## 0.2.17

- Ошибки отдельных соединений из журнала ядра больше не помечают весь VPN как неисправный и не отправляют ложный статус ошибки на часы.
- Неудачный запрос к контрольному HTTPS-адресу отображается как неподтверждённая проверка, а не доказательство остановки VPN.
- Подтверждённый HTTPS сохраняется при последующем отказе другого отдельного запроса. Фатальные ошибки запуска службы по-прежнему отображаются отдельно.
- Включены предыдущие локальные исправления проверки HTTPS через явный VPN-outbound и параметров сохранённых Reality-профилей.
- Проверка обновлений: Настройки → Обновление приложения; выпуски публикуются отдельно в NOVA-VPN-Android.

## 0.2.16

- Добавлены регрессионные тесты для ссылочных и полных sing-box конфигураций; пользовательский `domain_resolver` сохраняется.

## 0.2.15

- Регрессионный тест проверяет адаптацию TUN в полном импортированном конфиге.

## 0.2.14

- Изменён TUN-стек по умолчанию с `mixed` на `gvisor` для проверки и исправления прохождения TCP-трафика на Android.

## 0.2.13

- Добавлена диагностика ошибок VPN-транспорта: просроченный/неподходящий TLS-сертификат, таймаут и отказ сервера теперь показываются на главном экране и в уведомлении.
- Убрано ложное обещание «Вы защищены», если TUN включён, но профиль не может установить защищённое соединение с узлом.
- На MuMu Android 15 проверено: ошибка узла видна в интерфейсе; HTTPS через текущую подписку не проходит из-за отказа VLESS/REALITY-узла. Проверка сертификатов сохранена, TLS-проверка не отключалась.

## 0.2.12

- Исправлен порядок обработки DNS: DNS-пакеты перехватываются движком до правил приложений и сайтов, чтобы браузерный трафик не обходил DNS-обработчик.
- Добавлена Android-платформенная DNS-транспортировка для bootstrap-запросов на физической сети, без отправки этих запросов в создаваемый VPN-туннель.
- Сайтовые правила по-прежнему имеют приоритет над правилами выбора приложений; для DNS-запросов сайтов учитывается тот же выбор «через VPN» / «напрямую».
- Улучшено определение физической сети при запуске и обработка неизвестного владельца соединения на Android 10+.
- Проверено на MuMu Player с Android 15: VPN подключается, Chrome открывает `example.com`, а системный DNS-запрос и ICMP-запрос к домену проходят при активном туннеле.

- Часы сохраняют полученный профиль в локальном зашифрованном Android Keystore-хранилище и могут подключать собственный VPN-туннель независимо от телефона.
- Управление VPN телефона с часов оставлено отдельной кнопкой; переключение одного туннеля не должно менять состояние другого.
- Профиль передаётся только сопряжённым устройствам по нажатию пользователя; передача ограничена 90 КиБ.
