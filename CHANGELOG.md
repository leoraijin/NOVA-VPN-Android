# NOVA VPN Android — изменения

## 0.2.28

- Распространяемая сборка `optimized` без режима отладки: выключены отладочные проверки Compose и подробный поток событий/соединений sing-box. Сохранён прежний сертификат для установки поверх существующего клиента; сборка остаётся экспериментальной.
- Непрозрачные карточки без теней уменьшают слои отрисовки при прокрутке; списки серверов и сайтов переиспользуют строки своего типа.
- Монитор физической сети учитывает позднее появление интерфейса после смены Wi-Fi/мобильной сети. Одинаковые события больше не передаются ядру повторно; новая сеть, потеря сети и восстановление интерфейса передаются.
- Это исправление клиентской обработки сети; доступность конкретного сервера и скорость мобильного оператора требуют проверки на устройстве.

## 0.2.27

- Пошаговое обучение при первом открытии: добавление ключа/подписки/QR/файла, маршрутизация приложений, правила сайтов, выбор сервера, обновления с GitHub и подключение VPN.
- Шесть шагов переключают реальные вкладки, прокручивают к нужному блоку и выделяют карточку. Навигация обучения не подключает VPN и не меняет профили или маршруты.
- Кнопки «Назад», «Далее», «Готово» и «Пропустить»; сохранение шага при пересоздании экрана. Завершение/пропуск сохраняются до закрытия подсказок вне UI-потока. Повтор: Настройки → Обучение → Начать обучение.
- Длинный текст прокручивается отдельно; кнопки остаются видимыми. Автоматический запрос разрешения уведомлений и проверка обновлений отложены до выхода из обучения.
- Подпись в настройках уведомлений приведена к тихому поведению 0.2.26; само одно тихое уведомление сохранено.

## 0.2.26

- Оставлено одно постоянное уведомление NOVA VPN с именем конфигурации. Подключение, проверка HTTPS, смена профиля и повторная выдача разрешения обновляют эту же карточку.
- Удалено отдельное уведомление подключения высокой важности, которое создавало вторую карточку, звук и всплывающий баннер.
- Новый канал низкой важности создаётся без звука, вибрации и индикатора; он применяется и при обновлении поверх старого установленного клиента. Старое сообщение подключения отменяется автоматически.
- Для Android 7.x также выключены звук, вибрация и стандартные сигналы; приоритет низкий, обновления не повторяют оповещение.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.25

- Исправлена причина скрытых уведомлений на Android 13+: теперь приложение запрашивает POST_NOTIFICATIONS при первом открытии. Отказ не останавливает VPN, повторное включение доступно в настройках.
- После подключения или смены профиля показывается отдельное уведомление высокой важности «NOVA VPN · имя профиля». Повторные проверки трафика и применение маршрутизации к тому же профилю не вызывают новые всплывающие сообщения.
- Постоянное уведомление использует фирменный значок NOVA. Добавлен раздел Настройки → Уведомления о VPN; после выдачи разрешения уже активная служба обновляет уведомление без переподключения.
- Android/One UI управляет разрешением, показом баннеров и режимом «Не беспокоить»; заблокированные пользователем уведомления приложение не включает самостоятельно.

## 0.2.24

- Постоянное уведомление VPN показывает NOVA и имя активной конфигурации, а строка состояния меняется при подключении и проверке трафика.
- Имя профиля передаётся для обычного подключения, автоподключения, плитки, применения изменений маршрутизации и команды с часов.
- Уведомление содержит только выбранное пользователем имя профиля и состояние — без адресов серверов, подписок и ключей.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.23

- Маршрутизация: иконки готовятся вне UI-потока только для видимых строк. Кэш ограничен 64 иконками (около 2,25 МиБ пикселей); место иконки остаётся постоянным во время загрузки.
- Каталог приложений загружается только при открытии маршрутизации, без загрузки всех Drawable и метаданных на старте. Строки приложений используют отдельный тип переиспользования LazyColumn.
- Экран перестаёт собирать состояние VPN в фоне. Повторные неизменившиеся статусы не отправляются на часы и не обновляют плитку; ошибка доставки позволяет повторить отправку.
- Существующие VPN, проверка HTTPS и ручная передача профилей сохранены. Экономия батареи и плавность на физическом S24 ещё не измерены.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.22

- Настройки → Другие продукты: кнопки GitHub для Windows-клиента и Wear OS-клиента NOVA.
- Ссылки открываются в браузере или приложении GitHub; ошибка открытия отображается сообщением.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.21

- Серверы → «Передать на часы»: отдельная подписанная кнопка у каждого профиля и сообщение об ожидании ответа.
- Поиск именно NOVA Wear OS 0.3.4+, передача на одни часы и подтверждение после сохранения зашифрованного профиля. Ответ сопоставляется с устройством и конкретной передачей; через 25 секунд показывается тайм-аут.
- Ошибки доставки, поиска и сохранения больше не отображаются как успешная передача. Старый факт отправки сообщения не считается подтверждением.
- Обновить нужно оба приложения. Профиль передаётся вручную; VPN телефона и часов остаются независимыми.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.20

- Подтверждение обработки команды с часов: телефон отвечает, что принял подключение/отключение либо требуется профиль, разрешение или открытие приложения.
- Ошибки подготовки VPN и запрет запуска службы из фона обрабатываются без падения обработчика команды. Совместимо с Wear OS 0.3.2 и старыми командами часов.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.19

- Маршрутизация → карточка домена: кнопка с карандашом открывает редактирование адреса с сохранением выбранного маршрута и порядка правил.
- Добавлены проверка домена, нормализация регистра/IDN, запрет дубликатов и отмена без изменения настроек. Активный VPN автоматически переподключается с обновлённым правилом.
- Проверки: debug-сборка, 68 unit-тестов без ошибок, версия и подпись ARM64 APK. Интерфейс на физическом S24 ещё не проверен.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.18

- Плитка в шторке получила фирменный монохромный щит NOVA с буквой N вместо общего символа питания. Фон и окраску задаёт Android/One UI.
- Под названием NOVA VPN отображаются состояние туннеля и выбранный сервер; добавлено описание для экранного диктора.
- Неудачный контрольный HTTPS-запрос не делает плитку выключенной или ошибочной при активном туннеле.
- Проверены разрешения и совместимость подписи обновления. Предупреждение Google Play Защиты об неизвестном разработчике не объявляется исправленным: сканирование/рассмотрение выполняет Google, см. PLAY-PROTECT.md.
- Обновления: Настройки → Обновление приложения; https://github.com/leoraijin/NOVA-VPN-Android/releases

## 0.2.17

- Ошибки отдельных соединений из журнала ядра больше не помечают весь VPN как неисправный и не отправляют ложный статус ошибки на часы.
- Неудачный запрос к контрольному HTTPS-адресу отображается как неподтверждённая проверка, а не доказательство остановки VPN.
- Подтверждённый HTTPS сохраняется при последующем отказе другого отдельного запроса. Фатальные ошибки запуска службы по-прежнему отображаются отдельно.
- Включены предыдущие локальные исправления проверки HTTPS через явный VPN-outbound и параметров сохранённых Reality-профилей.
- Проверка обновлений: Настройки → Обновление приложения; выпуски публикуются отдельно в NOVA-VPN-Android.

## 0.2.16

- Исправлен bootstrap DNS для hostname VPN-сервера: proxy outbound теперь явно разрешает адрес сервера через локальный DNS, чтобы не зависеть от DNS, который сам маршрутизируется через этот proxy.
- Добавлены регрессионные тесты для ссылочных и полных sing-box конфигураций; пользовательский `domain_resolver` сохраняется.

## 0.2.15

- Android теперь принудительно адаптирует TUN-стек импортированных sing-box JSON-профилей к проверенному `gvisor`, а не сохраняет несовместимый с устройством `system`/`mixed`.
- Регрессионный тест проверяет адаптацию TUN в полном импортированном конфиге.

## 0.2.14

- Изменён TUN-стек по умолчанию с `mixed` на `gvisor` для проверки и исправления прохождения TCP-трафика на Android.

## 0.2.13

- Добавлена диагностика ошибок VPN-транспорта: просроченный/неподходящий TLS-сертификат, таймаут и отказ сервера теперь показываются на главном экране и в уведомлении.
- Убрано ложное обещание «Вы защищены», если TUN включён, но профиль не может установить защищённое соединение с узлом.
- На MuMu Android 15 проверено: ошибка узла видна в интерфейсе; HTTPS через текущую подписку не проходит из-за отказа VLESS/REALITY-узла. Проверка сертификатов сохранена, TLS-проверка не отключалась.

## 0.2.12

- Исправлен порядок обработки DNS: DNS-пакеты перехватываются движком до правил приложений и сайтов, чтобы браузерный трафик не обходил DNS-обработчик.
- Добавлена Android-платформенная DNS-транспортировка для bootstrap-запросов на физической сети, без отправки этих запросов в создаваемый VPN-туннель.
- Сайтовые правила по-прежнему имеют приоритет над правилами выбора приложений; для DNS-запросов сайтов учитывается тот же выбор «через VPN» / «напрямую».
- Улучшено определение физической сети при запуске и обработка неизвестного владельца соединения на Android 10+.
- Проверено на MuMu Player с Android 15: VPN подключается, Chrome открывает `example.com`, а системный DNS-запрос и ICMP-запрос к домену проходят при активном туннеле.

## 0.2.11

- Ограничен MTU виртуального Android VPN-интерфейса значением 1500, чтобы избежать зависания трафика на сетях и прошивках, не поддерживающих jumbo-пакеты.
- Добавлены тесты для граничных значений MTU.

## 0.2.10

- Добавлена плитка NOVA VPN в системные быстрые настройки Android: показывает состояние туннеля и выбранный сервер, нажатием подключает или отключает VPN.
- Добавлена кнопка добавления плитки в настройки приложения. Если Android ещё не выдавал разрешение на VPN, клиент откроется и запросит его штатным способом.

## 0.2.9

- Исправлены два нативных вылета при подключении: адреса сетевых интерфейсов передаются sing-box в формате CIDR без IPv6 zone id, а нераспознанный Android-владелец соединения возвращается как безопасный пустой результат.

## 0.2.8

- Обновлён встроенный Android VPN-движок libbox с 1.14.0 до 1.14.1: в отчёте о сбое 0.2.7 зафиксирован повторяющийся нативный SIGABRT внутри libbox.
- Добавлены безопасные диагностические отметки этапов запуска VPN без записи конфигурации, адресов серверов и ключей в журнал.

## 0.2.7

- Добавлена явная отправка подготовленной VPN-конфигурации на часы из списка серверов; автоматической передачи нет.
- Часы сохраняют полученный профиль в локальном зашифрованном Android Keystore-хранилище и могут подключать собственный VPN-туннель независимо от телефона.
- Управление VPN телефона с часов оставлено отдельной кнопкой; переключение одного туннеля не должно менять состояние другого.
- Профиль передаётся только сопряжённым устройствам по нажатию пользователя; передача ограничена 90 КиБ.

## 0.2.6

- Синхронизация с Wear OS больше не меняет данные статуса одной только меткой времени. Повтор одинакового состояния не создаёт лишнее срочное событие для часов.

## 0.2.5

- Исправлена обработка QR-кодов и скопированных ссылок с BOM, пробелами, Unicode-именами и неэкранированным знаком `%`.
- При действительно некорректной ссылке теперь показывается причина ошибки URI, а не только общий текст «некорректная ссылка».

## 0.2.4

- Добавлен импорт профиля через QR-код: сканируется QR со ссылкой, подпиской или текстом sing-box; предпросмотр проходит через ту же проверку, что и ручной ввод.
- Добавлен системный выбор файла конфигурации без запроса доступа ко всему хранилищу. Поддерживаются текстовые конфиги и JSON до 4 МБ; проверяются кодировка и содержимое файла.
- QR-сканер работает на устройстве через Google Code Scanner и не требует отдельного разрешения камеры. Если сканер недоступен, остаётся импорт из файла или вставка ссылки.

## 0.2.3

- Исправлена главная карточка: статус больше не зажимается рядом с кнопкой; кнопка подключения получила чистую круглую форму без внутренней гранёной поверхности.
- Добавлены все пять оформлений Windows-клиента: iOS 27 · Liquid Glass, Amber Glass, One UI 8.0, Windows 11 Light и Windows 11 Dark. Старые сохранённые темы автоматически сопоставляются с ближайшими новыми.
- Добавлена маршрутизация по доменам с выбором «через VPN» или «напрямую», включая поддомены.
- Сайтовые правила имеют приоритет над правилами выбора приложения/браузера: приложения теперь маршрутизируются внутри sing-box, а не отсекаются на уровне TUN.
- Добавлены проверки доменов и тесты порядка правил; сам NOVA остаётся исключён из туннеля, чтобы не создавать петлю.

## 0.2.2

- Исправлены пропорции иконки: щит и знак N теперь целиком находятся в безопасной зоне адаптивного значка Android, поэтому края не должны обрезаться маской лаунчера.
- Обновлены цветной, монохромный и совместимый со старыми версиями Android варианты значка; задан тот же ресурс для круглых лаунчеров.

## 0.2.1

- Добавлена отдельная тема «Сливочный» по новому референсу: тёплый ванильный фон, мягкие бежевые поверхности и голубые акценты.
- Главная переработана: крупнее статус подключения, круглая кнопка с тонким контуром и быстрый выбор до трёх серверных профилей.
- Быстрая смена сервера сохраняет выбранный профиль и применяет его к активному VPN-туннелю.

## 0.2.0

- Иконки приложений в списке маршрутизации.
- Сохраняемые темы оформления: лавандовая, небесная и тёмная.
- Автопроверка GitHub Releases при запуске, ручная проверка и показ примечаний к версии.
- Отдельный Wear OS-пульт: статус и команды подключения синхронизируются с телефоном; любые данные профиля и ключи на часы не отправляются.
- Уточнена видимость запускаемых приложений, совместимость с Android API 24+ и исключение данных VPN из резервных копий.

## Обновление

После публикации APK откройте страницу Releases в репозитории NOVA-VPN-Android. Клиент также предложит загрузить новую версию при запуске, если в публичном репозитории появится релиз с более высоким номером.
