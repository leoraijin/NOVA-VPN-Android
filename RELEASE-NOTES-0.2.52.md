# NOVA VPN Android 0.2.52

- Исправлен импорт XHTTP / SplitHTTP из VLESS, Trojan, VMess и Xray JSON-подписок.
  Добавлен нативный XHTTP-движок sing-box-lx; доступны auto, packet-up, stream-up,
  stream-one. Сохраняются host, path, mode, TLS/Reality, параметры extra и XMUX.
- Добавлен импорт HTTPUpgrade и HTTP/H2 ссылок. Неподдерживаемая запись больше
  не удаляет остальные корректные записи JSON-подписки. Причины пропусков видны
  на странице серверов; ограничения 4 МБ / 2000 профилей сохранены.
- Группировка серверов по стране, транспорту, протоколу и подписке во всех
  оформлениях. Страна определяется по названию/флагу, не по IP-геолокации.
  Повторный импорт сохраняет ID выбранного сервера и добавляет источник подписки.
- Настройки → Уведомление VPN → Скрыть / показать карточку NOVA открывает
  отдельный канал Android «Состояние NOVA VPN». Отключите его, чтобы убрать
  карточку подключения. VPN продолжит работать; системный значок VPN и список
  активных приложений управляются Android.

Проверка: 219 unit-тестов (218 успешно, один пропущен); сборка optimized.
Все четыре режима XHTTP передали данные против официального Xray 26.10.21:
локальный тест на ПК и настоящий VpnService в MuMu Android 15 / x86_64,
отдельный UID, IPv4 и IPv6. UI: фильтрация стран, сохранение группировки,
открытие канала уведомлений. Подпись совпадает с 0.2.51.

Границы проверки: использовались искусственные конфигурации без ключей подписки.
Физический телефон не определился по USB. Реальные серверы провайдера, XHTTP
через CDN/TLS/Reality и все расширенные комбинации extra отдельно не проверены.
XHTTP downloadSettings с отдельным downlink пока не поддержан и выдаёт причину
пропуска. XHTTP предназначен для движка sing-box; экспериментальный Reality Core
не обновлялся. Устаревшие импортированные подписки нужно импортировать повторно.
