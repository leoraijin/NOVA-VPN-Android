## Граница доказательств

Подтверждены идентичность опубликованных входных библиотек и заявленная upstream цепочка исходников. Это не доказывает независимую воспроизводимость их C++ сборки. Подписанная attestation в этом аудите не получена.

674-байтный LICENSE Android-модулей — лицензия cronet-go. Он не заменяет полный набор уведомлений для C++/Chromium и всех реально связанных сторонних компонентов. Исходный naiveproxy tar содержит их исходные документы, но список реально связанных GN targets, build/toolchain dependency closure и итоговые распространяемые notices ещё требуют отдельной работы. Gate не объявлен закрытым.

Полные машинные данные: `cronet-pinned-metadata.json`, `cronet-android-inputs.json`. Скрипт `build/Inventory-CronetInputs.py` только читает файлы и считает хэши; сборку/тесты не запускает. Манифест новых source-архивов перечисляет эти материалы отдельно с SHA-256.

## Кандидат уведомлений — 26.10.2026

`Collect-CronetNotices.py` проверяет SHA исходного tar и четырёх libcronet.a,
сохраняет 37 исходных лицензионных документов и 36 README.chromium с исходными
байтами. Все явно указанные в этих README файлы лицензий найдены. Отсутствие
README у компонента этим не исключается.

Во входных архивах имена объектов уплощены. Среди 2682 различных имён 2145 имеют
единственный совпадающий basename в исходниках, 160 неоднозначны, 377 относятся
к несопоставленным/генерируемым файлам. Даже единственный basename не доказывает
фактический путь компиляции; заголовочные inline-компоненты так не учитываются.
Поэтому это инвентарь кандидатов, не полный GN/link graph или итоговый NOTICE.

Для Perfetto в исходном DEPS закреплён 9ede949f025303868fa0c42418f122ac47312539;
контрольный cpu_info.cc побайтово совпал с upstream, LICENSE совпал с Git blob
681d40008ee32ddb7e4e1413d6bf82c4f68c5b5b. В сохранённом source tar его корневого
LICENSE нет; оригинал теперь сохранён как supplemental notice.

Для Protobuf заголовок версии 6.33.0 побайтово совпал с v33.0, commit
a79f2d2e9fadd75e94f3fe40a0399bf0a5d90551. Контрольный message_lite.cc содержит
локальную правку: удалён internal Abseil include, resize helper заменён на
output->resize; лицензионный заголовок совпадает. Сохранён upstream LICENSE
этой версии, но полной эквивалентности ревизии компонента не заявляется.

Тексты, SHA и первичные URL находятся в cronet-supplemental-notices.json.
Формат существующего source-пакета уже включает provenance JSON с хэшами;
это не меняет Android-бинарники. Кандидат сборки уведомлений принимает этот JSON
явным параметром --supplemental-notices. GN/build dependency closure,
генерируемые/неоднозначные объекты и итоговая распространяемая подборка остаются
незакрытыми. Нового runtime-подтверждения или юридического заключения здесь нет.
