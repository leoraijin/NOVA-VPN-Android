# NOVA VPN Android 0.2.55 — кандидат

Исправлена гонка удаления и импорта: импорт, запущенный до удаления всех конфигов
или полного восстановления каталога, больше не может записать устаревшие серверы
и подписки обратно. Проверка поколения и запись проходят под одним замком.
Пользователь получает сообщение об отмене импорта и может начать его заново.

В изолированном Android API35 CI прошли реальные Android Keystore/AtomicFile,
отказ запоздавшего ручного и подписочного импорта без изменения зашифрованных
байтов, HTTP 200/304/401 после удаления, отмена/подтверждение, повторное открытие.
Также прошли шесть WorkManager-фаз и восемь вариантов библиотеки из 2000 серверов
с поворотом экрана и пересозданием Activity. Unit: 344 всего, 343 PASS, один optional skip.
Проверенный код: fe454b42795100d5b93e55236404adb22b921e4a; последующие изменения
подготовки версии не меняют эту логику.

Проверка: https://github.com/leoraijin/NOVA-VPN-Android/actions/runs/41490821348
Артефакт SHA-256: ca401ba410d68c280780d38ebc35a4b6bcc411101e655c79fb66dd630ffe4b07.

Нативные ядра и схема хранилища не меняются. Три gRPC-сервера из предыдущего
реального теста остаются неработоспособными по неустановленной причине; этот
кандидат не объявляет исправление gRPC. Эталонное сравнение на телефоне ожидает
прямого подтверждения пользователя после отказа автоматической проверки разрешений.

Кандидат ещё не опубликован как стабильный APK. Проверка финального пакета,
подписи и обновления должна быть завершена отдельно. Общий семипунктовый план
и Windows-план этим исправлением не объявляются завершёнными.
