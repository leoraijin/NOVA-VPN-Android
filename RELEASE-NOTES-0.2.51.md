# NOVA VPN Android 0.2.51 — исключение приложений из VPN

Основной клиент, versionCode 53, прежняя подпись. ARM64 APK устанавливается
поверх основной NOVA без удаления приложения.

- Выбранные исключённые приложения используют обычную сеть Android,
  включая DNS, вместо direct-outbound внутри VPN-интерфейса.
- В режиме с непустым списком «Только отмеченные» остальные приложения
  остаются вне VPN. Правила сайтов действуют внутри допущенных в VPN приложений.
- Исправление применяется к sing-box и Reality Core.
- Защита от захвата всех приложений, если выбранный allow-list опустел после удаления.

Это не полное сокрытие факта VPN от любых детекторов Android.
Пустой режим «Только отмеченные» сохраняет прежний direct/site план внутри TUN.
Android lockdown может блокировать прямой доступ; NOVA не обходит его.

Проверено локально: 208 unit-тестов успешны, один пропущен; обычный optimized
APK собран; обновлённый Android smoke-тест компилируется. Подпись совпадает
с 0.2.50. Новая маршрутизация на телефоне/эмуляторе ещё не проверена.

Код приложения: 497ed9c0ed19ea7b5a63e4ad421f9cec6c8a2abc.
ARM64 Reality/JNI библиотеки сохранены из проверенного 0.2.50 без изменений.
Подробные ограничения: APP-BYPASS.md в исходниках.

В этом выпуске APK предоставляется для ARM64. Старые релизы не перезаписаны.
