# Security vulnerability reports

Do not disclose VPN profiles, private keys, subscription URLs, or sensitive logs in public Issues or Pull Requests.

As of the audit on 6 October 2026, a private vulnerability-reporting channel has not been confirmed. The owner should enable GitHub Private Vulnerability Reporting for this repository or provide a verified private contact that is regularly monitored. Until then, ask the owner for a safe channel before sharing sensitive details.

This file recommends a process; it does not claim that GitHub security settings are enabled or that any channel is monitored.
